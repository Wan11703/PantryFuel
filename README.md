# PantryFuel

PantryFuel is a smart pantry, recipe recommendation, and nutrition tracking application.

It helps users:

- Track ingredients currently available in their kitchen
- Discover recipes based on available ingredients
- Prioritize ingredients that are close to expiring
- Track calories and macronutrients
- Find meals that better fit remaining daily nutrition targets
- Reduce unnecessary food waste

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

### Backend

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- PostgreSQL
- Alembic
